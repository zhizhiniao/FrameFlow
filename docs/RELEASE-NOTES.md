# 帧流 FrameFlow 0.3.4

新增微信视频号下载：先在帧流点击「开始抓取」，等待就绪后到电脑版微信播放视频；在右侧选择封面，再点击左侧「下载所选视频」。

- 抓取结果与本地视频库在右侧切换；左侧集中显示抓取与下载状态。
- 新增视频号媒体库分类、候选去重、上次候选恢复和已保存状态，避免重复下载。
- 保存前校验完整视频；文件通过校验后才进入媒体库。
- 界面统一为暖灰、米白与陶土橙，精简重复说明，支持宽窄窗口。
- 修正候选卡片下载完成后仍显示「下载中」的问题。

**安装与更新**

完整解压 Windows x64 ZIP 后运行 `FrameFlow.exe`。0.3.0 及以上版本可通过内置更新器接收本次正式更新；0.2.x 需要先手动升级一次。软件未运行或无法连接 GitHub 时，需要恢复运行与联网后才能检查。

**实测与边界**

在 Windows、微信 4.2.0.53 完成动态抓取和确认下载实测；候选封面与成品首帧一致，视频与音频完整解码通过。微信可能预加载其他内容，请按封面选择。其他微信版本、直播与无人值守批量未验收。

微信抓取引擎采用 GPL-3.0，随包提供源码、完整许可证和构建说明；来源及修改见 [微信组件说明](https://github.com/zhizhiniao/FrameFlow/blob/main/docs/WECHAT-SOURCE.md)。不打包用户视频、登录资料、签名媒体地址或解密文件头。

# 帧流 FrameFlow 0.3.1

- 首次公开发布，Windows 10/11 x64 便携版；完整解压后运行 FrameFlow.exe。
- 新 Logo 与发条、一幕保持同系列配色。
- 修正任务栏显示为 PowerShell 图标：窗口、桌面快捷方式使用帧流独立身份与重启图标。
- 默认自动检查更新，后台下载并校验新版，准备好后提示“更新并重启”。
- 更新时等待任务结束，保留登录资料、设置和用户媒体；替换失败回退程序文件。
- 增加版本状态、手动检查入口、完整更新说明及作者联系方式。

旧 0.2.x 用户需要手动下载此版一次，之后即可接收正式 Release 更新。
软件未做 Windows 代码签名；平台下载能力受账号、网络和平台变化影响。
