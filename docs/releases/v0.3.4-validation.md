## 0.3.1 → 0.3.4 实网验证

1. **旧包来源**：使用公开发行的 0.3.1 ZIP，SHA-256 与 GitHub 元数据一致：`d5ff81dca99cabf5ceb5def088a0b438f38f55b144bf606c20c7c864d2467f3e`。
2. **原更新器下载**：没有修改旧版 `Update.Check.ps1`。在独立用户目录连接真实 GitHub latest 接口，下载完整 0.3.4 ZIP、核对下载大小/SHA-256、解压并逐文件核验，返回 `Ready 0.3.4`。
3. **自动提示**：加载未修改的旧版 XAML 和 `VideoDownloader.Update.ps1`，使用其原有 12 秒自动定时器；未手动调用检查。约 12.5 秒开始检查，约 21.6 秒显示「新版 v0.3.4 已准备好」，按钮为「更新并重启」。
4. **实际覆盖升级**：由旧版 `Update.Apply.ps1` 将真实校验目录安装到隔离的 0.3.1 程序目录，结果为 0.3.4，视频号引擎和界面模块均存在。
5. **保留文件**：隔离设置文件、样本视频、额外放入程序目录的用户文件，升级前后 SHA-256 均相同。

下载/校验与提示展示分两步验证；提示模块使用的是旧版原更新器生成的真实已校验缓存。21.6 秒不包含完整 ZIP 的下载时间。
升级测试使用 `-NoRestart`；未对用户正在运行的程序目录执行覆盖，也未把隔离哨兵文件称为真实账号登录验收。

## 边界

- 已实测 0.3.1 的更新器、自动提示模块和覆盖升级；未声称所有历史版本或其他电脑逐一验证。
- 0.3.0 起包含更新器；0.2.x 没有该能力，需要手动升级一次。
- 软件未运行、离线或 GitHub 无法访问时，需恢复运行与联网；下载完整包并完成校验后才显示更新已准备好。
