1. 使用原 0.3.4 完整便携目录及未修改的 `Update.Check.ps1`，从全新隔离数据目录访问真实 GitHub latest 与公开下载地址。
2. 原更新器完成完整 ZIP 下载、大小/SHA-256 校验、解压和逐文件清单核验，返回 `Ready 0.3.6`；本次耗时 121.77 秒。
3. 原 0.3.4 `Update.Apply.ps1` 将真实下载的校验目录覆盖到隔离旧版，安装版本变为 0.3.6，Worker 哈希与正式包一致；下载校验加安装总计 135.77 秒。
